# 模拟铁轨 · 操作指南

一个 3D 火车沙盘：在一片空地上铺铁轨、拼闭环、扳道岔，再让列车跑起来。
本文是**按键与流程**的速查手册，设计背景见《01-概要设计.md》。

> 本文有一份排好版的 PDF：`docs/模拟铁轨-操作手册.pdf` —— 它由本文件自动排版生成
> （`python scripts/manual_pdf.py` 可重新印一份）。

---

## 一、启动

在项目根目录下用 `run.bat` 启动（脚本会自己激活 `train3d` 环境）：

```
run.bat                            空场地，从零开始铺轨
run.bat --list-scenes              列出所有现成场景
run.bat --scene valley             直接进入「山谷环线」，列车已上线
run.bat --scene overpass           进入「立体交叉」
run.bat --open saves\layout.json   读取存档继续编辑
run.bat --help                     看全部命令行参数
```

等价写法：`python app/main.py ...`（`run.bat` 只是帮你省掉激活环境那一步）。

### 用 exe 启动（机器上没装 Python）

`TrainGame.exe` 是一个自带 Python、Panda3D 与件库数据的单文件程序，**双击即可开跑**，
不需要装 Python、也不需要 `run.bat`：

```
TrainGame.exe                            双击就是空场地，从零开始铺轨
TrainGame.exe --scene valley             直接进入「山谷环线」，列车已上线
TrainGame.exe --open saves\valley.json   读取存档继续编辑
TrainGame.exe --list-scenes              列出所有现成场景
TrainGame.exe --help                     看全部命令行参数
```

参数与 `run.bat` **完全一样**（`--scene` / `--open` / `--width` / `--height` …）。
只有一点不同：窗口版程序没有控制台，所以 `--list-scenes` 与 `--help` 会**另开一个
命令行窗口**把内容打出来，看完按回车关掉。

和 exe 有关的三个位置：

| 项 | 在哪 | 说明 |
|---|---|---|
| 存档 | exe 旁边的 `saves\` | 目录不存在会自动建；exe 放在只读位置（如 `Program Files`）时才退回 `%LOCALAPPDATA%\TrainGame\saves` |
| 日志 | exe 旁边的 `train3d_log.txt` | 每次启动重写；出问题时先看它（启动失败弹的窗里也会写这个路径） |
| 示例存档 | exe 旁边的 `saves\*.json` | 打包时一并铺好，所以 `--open saves\valley.json` 开箱可用 |

> **从 exe 启动时，存档不在仓库里，而在 exe 旁边那个 `saves\`。** 这是有意的：
> 单文件 exe 每次启动都会解包到一个临时目录、退出时整个删掉，存档要是落在那里，
> 就会"提示已保存、关掉游戏文件就没了"，而且全程不报错。放在 exe 旁边还有个好处
> —— 整个文件夹拷进 U 盘，存档跟着一起走。从 `run.bat` 启动时存档才落在仓库的
> `saves\`，两者互不影响。

## 二、视角与鼠标

| 操作 | 效果 |
|---|---|
| 左键（放置模式） | 放下一节轨道 |
| 左键（视角模式） | 按住拖拽 = 环绕视角 |
| 右键 按住拖拽 | 环绕视角 |
| 中键 按住拖拽 | 平移视角 |
| 滚轮 | 拉近 / 拉远 |

键盘视角：

| 键 | 效果 |
|---|---|
| `V` | 在「放置轨道」和「左键拖拽视角」之间切换 |
| `W` `A` `S` `D` | 平移视角 |
| `Q` `E` | 转向 |
| `F` | 取景：自动框住整个场地 |
| `Esc` | 重置待放件朝向 |

> 视角模式 = 左键不再放轨道、而是拖视角，专门给「摆完轨道想四处看看」用。
> 召唤列车时会自动切到视角模式。

> **拖拽方向一律「抓住画面拖」**：鼠标往右拖，场地就跟着往右走；往上拖就往上去。
> 环绕与平移两个轴的手感是统一的（和 Google Earth 那类地图应用一致）。

## 三、铺轨道

1. 按 `,` / `.` 在分类间切换：**直轨 → 曲线 → 坡道 → 高架桥 → 交叉 → 道岔 → 终端**。
2. 按 `[` / `]` 在同类里换下一件（或按 `1`–`9` 直选第 n 件）。
3. 移动鼠标，轨道会吸附到最近的空闲端口（白/高亮标记）。
4. 左键放下。

| 键 | 效果 |
|---|---|
| `,` / `.` | 换分类 |
| `[` / `]` | 换同类里下一件 |
| `1`–`9` | 直选第 n 件 |
| `R` / `Shift+R` | 旋转待放件（顺 / 逆时针） |
| `T` | 切换接驳端口（从 a 端还是 b 端接上去） |
| `Enter` | 确认放置 |
| `Esc` | 重置待放件朝向 |

### 一键闭合

拼环最后差一两节时，很难心算出「还差多少、该用哪一节」。按 `C`：

- 先拿手上这一节试，合得上就用它；
- 合不上就**自动换一件合适弧度/长度的轨道**补完，并在提示里说清换成了哪一件。

`C` 做的是把首尾那道**缝写进存档**。如果首尾本来就已经吸附得严丝合缝（差 0.0000 m），
它只会补上这条缝、一节都不多接 —— 而那种情况下列车**本来就能绕着跑**（判据是几何，
见 §九）。所以按 `C` 不是"让车能开"，而是"把这一圈固定下来"。

## 四、道岔与删除

| 键 | 效果 |
|---|---|
| `U` | 扳道岔（把鼠标移到道岔上再按） |
| `X` / `Delete` | 只删掉鼠标下这一节，其余轨道**原地不动** |

删除后后半截会原地冻结成一个真实缺口，可以再放一节补上、或按 `C` 一键闭合。

> **道岔档位**：左开/右开道岔都有「直股」和「岔股」两档，`U` 在两档间循环。
> 列车只会走当前档位那条 route，另一条是死路。

## 五、布景（建筑 · 车站 · 山 · 树木 · 湖泊 · 绿地）

按 `B` 进入**布景模式**（再按 `B` 回到放置轨道）。这个模式专门用来手工摆放
建筑、车站、山、树木、湖泊、绿地这些环境物件，让场景更生动。

布景和轨道一样按**分类**组织，每个分类里又有若干件（数字键直选）：

| 键 | 效果 |
|---|---|
| `B` | 进入 / 退出布景模式 |
| `,` / `.` | 换布景分类 |
| `[` / `]` | 换同类里下一件 |
| `1`–`9` | 直选同类里第 n 件 |
| `R` / `Shift+R` | 旋转待放件（顺 / 逆时针） |
| `Esc` | 待放件朝向归零 |
| 左键 / `Enter` | 在鼠标指着的地面放下 |
| `X` / `Delete` | 删掉鼠标正悬停的布景（含场景自带的建筑 / 车站 / 山 / 树 / 湖 / 绿地） |

六个分类：

| 分类 | 物件 | 说明 |
|---|---|---|
| 建筑 | 普通民房 / 别墅 / 公寓 / 板楼 / 高楼 / 商场 / 便利店 | 从村屋到高层，体量与立面各异 |
| 车站 | 老式车站（古典） | 山墙坡屋顶、钟塔尖顶、拱形窗、石墙 |
| 车站 | 新式车站（现代） | 玻璃幕墙、悬挑平屋顶、钢柱 |
| 山 | 大山 / 山丘 / 山梁 / 岩峰 / 雪山 / 台地 / 火山 | 锥峰、草丘、拉长山梁、峭壁、雪线、平顶、火山口 |
| 树木 | 针叶松 / 阔叶树 / 白杨 / 棕榈 / 云杉 / 垂柳 / 灌木 / 柏树 | 树冠与树干各异 |
| 湖泊 | 小水塘 → 巨型湖（五档） | 从小到大，带沙滩环与深水心 |
| 绿地 | 小草坪 → 大草原（五档） | 从小到大的贴地草皮 |

> 老式 / 新式车站都在「车站」分类里，放下时会**自带一条站台**（正立面外，黄线朝
> 轨道一侧）。手工放下的布景、以及删掉的场景自带件，都会跟着存档保存
> （读档后原样恢复）；撤销 / 重做同样对布景生效；悬停时有高亮轮廓，移开即消失。

## 六、撤销 / 存档

| 键 | 效果 |
|---|---|
| `退格` / `Z` / `Ctrl+Z` | 撤销 |
| `Shift+Z` / `Y` / `Ctrl+Y` | 重做 |
| `Ctrl+S` | 另存为（系统文件对话框，滤镜 `*.json`） |
| `Ctrl+O` | 读档（系统打开对话框；有未保存改动时先问是否保存） |
| `Ctrl+N` | 清空场地 |

存档只记轨道拓扑（位姿由父子链重建），因此读档后几何仍然严丝合缝。

> **存档存在哪个目录**：从 `run.bat` 启动存在仓库的 `saves\`；从 `TrainGame.exe`
> 启动存在 **exe 旁边**的 `saves\`（理由见「一、启动」）。两者互不影响。对话框默认就打开这个目录。

> **存读档**：`Ctrl+S` 或左栏「存档」→ 系统**另存为**；`Ctrl+O` 或「读取」→ 系统**打开**。
> 有未保存改动时，读档前先问 `Y` 先保存 / `N` 不保存直接读 / `Esc` 取消。读入会
> **清空并替换**当前场景。

## 七、驾驶列车

| 键 | 效果 |
|---|---|
| `N` | 召唤列车（自动切到视角模式，反复按可在目录间换车） |
| `M` | 收起列车 |
| `↑` | 牵引（加速），共 4 档 |
| `↓` | 制动（减速），共 4 档 |
| `空格` | 惰行（松手柄，既不牵引也不制动） |
| `K` | **换向**：先快速刹停，再反向满牵引加速 |
| `J` | **鸣笛**（低音风笛）：只有列车在线时才会响 |
| `Shift+空格` | 紧急制动（制动力远大于常用制动，一把拉死） |

驾驶说明：

- **音效**：列车一上线就有**引擎声**（怠速时很轻），动起来之后叠加一层**连续的轮轨滚动声**，两者都随速度实时变速 —— 越快越响、音调越高；按 `J` 是风笛。音效在运行时程序化合成，无需任何音频资源文件。
  两条音轨里**都没有打点 / 电子提示音**：轮轨声刻意做成无瞬态的连续底噪，所以提速也只会变亮变响，不会变成"嗒嗒嗒"。
- **手柄是一根**：正数是牵引、负数是制动、0 是惰行，牵引和制动不会同时给。
- **紧急制动是锁存的**：拉了之后只有「回中位（空格）」或「重新给牵引（↑）」才能解除，再点一下 ↓ 不会把它降级。
- **换向 `K`**：按下去先紧急刹停，速率归零后方向翻个、自动给满牵引反向起步，
  反向加速度和正常加速**完全一样**。过程中按 ↑↓ / 空格即接管、取消换向。
- 列车能在**一条连通的线**上跑：闭环绕圈，开链跑到尽头自动停；扳道岔改线时会
  顺着新路继续走，不会突然变向或瞬移。
- **环的判据是几何，不是"有没有按 C"**：只要首尾吸附到严丝合缝（缝宽小于 1e-6 m），
  那条链就已经是环了 —— 列车会绕着跑，不会停在一道看不见的缝上。按 `C` 是把这道缝
  **写进存档**（HUD 上会提示"接缝已对齐但没焊死 —— 按 C 把它固定进存档"），以后接着
  往这条链上加件时，不会因为缝没存下来而把它重新变回开链。

> 手柄档位与动力学按车型质量 / 功率 / 黏着标定；当前目录里的黄丝带 400BF
> 加速猛、极速高，体感与程序化车体时代一致。

屏幕版面（v2.0；键位全部保留，主要操作也可点）。面板为**中性灰度**。

| 区域 | 内容 |

| 键 / 控件 | 效果 |
|---|---|
| `G` | 显示 / 隐藏网格 |
| `P` | 显示 / 隐藏端口标记 |
| `L` | 显示 / 隐藏闭环彩带 |
| `H` / 左栏「帮助」 | 打开 / 关闭中央短帮助 |
| 左栏「夜景」 | 夜景总开关：门前径向光晕、墙面洗光、楼窗灯，以及暖色环境光 |
| 左栏「固定」 | 钉住分类列：开启后切模式抽屉不收 |

未上线时底栏保留但灰显；上线后表盘与档位可点，与 `↑↓` / 空格 / `K` / `J` 双向同步。

## 九、常见问题

- **列车不上线 / 提示「先按 N」**：轨道被拆成互不相连的几段，或场地还是空的。把轨道接成一条连通线再按 `N`。
- **放不了轨道**：当前在视角模式，按 `V` 切回放置模式；或目标端口已被占用。
- **合不上环**：按 `C` 让程序自动补线，别手动去凑弧度。
- **「立体交叉」场景里列车钻桥下后停下**：疏解线是条尽头线，钻过去后不会自动绕回环上 —— 把道岔扳回直股即可回环线。
